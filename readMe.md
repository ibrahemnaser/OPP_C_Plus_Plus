# C++ Object-Oriented Programming Tutorial

This repository contains my learning journey through Object-Oriented Programming (OOP) concepts in C++ using the Udemy course. The project is designed to demonstrate fundamental OOP principles and best practices.

## Prerequisites

- C++17 or later
- A modern C++ compiler (g++, clang++)
- CMake (optional, for build system)

## Building and Running

The project can be compiled and run using any modern C++ compiler. Example commands:

```bash
# Using g++
g++ -std=c++17 main.cpp -o program
./program
```

## Learning Objectives

This project aims to demonstrate:

- Class definitions and object creation
- Encapsulation and data hiding
- Inheritance and polymorphism
- Header files and implementation separation
- Best practices in C++ OOP
